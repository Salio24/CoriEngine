Detailed Description

A Trigger components is used in combination with RigidBody component used to respond to an entity getting into a specific area that has the Trigger.

For a Trigger to work you need to attach a shape (From now on I will refer to shapes created like this as a Trigger zone) to the RigidBody body component with the following params:
filter.categoryBits = Cori::Physics::CollisionBits::SensorBit;
isSensor = true;
enableSensorEvents = true;
Trigger can register and update a limited amount of entities inside of it at the same time, this is controlled by CORI_MAX_TRIGGER_VISITORS define, default is 4, you can increase it if you need to.
When an entity enters the Trigger zone it will. All the function calls I'm referring to below is calls to the current TriggerBehaviour instance. (Lets say N is the tick entity exits the Trigger zone)
Tick 1: Fire OnEnter
Tick 2 - (N - 1): Fire OnTickUpdate
Tick N: Fire OnTickUpdate and then OnExit.
The order in which the OnTickUpdate fires for each Entity currently in the Trigger zone is not enforced or guaranteed to be in any particular order.
