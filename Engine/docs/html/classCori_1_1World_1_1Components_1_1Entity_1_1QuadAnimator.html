Detailed Description

Responsible for playing animations when attached to an entity.

QuadRenderer of the entity will be somewhat locked when QuadAnimator is attached to the entity, the only thing you can do is change tint color. If an entity doesn't have QuadRenderer upon addition of QuadAnimator, it will be added.

Changes the size scale.

Since you cannot control the size of the sprite that will be rendered from the QuadRenderer, you can change the size scale here, it's a modifier.
Final half size is calculated as follows: renderer.m_HalfSize = animationFrameSize * m_SizeScale / 2.0f;
